🌐 My Portfolio

Personal Portfolio Website

📌 About the Project

My Portfolio is a personal website developed to showcase my technical skills, web development projects, and professional profile. It provides a simple and interactive way for visitors to learn about me, explore my work, and connect with me.

The website is designed with a clean interface, smooth navigation, and a responsive layout to provide a good user experience across different devices.

🎯 Objectives

- To create a professional online presence.
- To showcase my technical skills and projects.
- To demonstrate my web development knowledge.
- To make it easier for recruiters and potential clients to contact me.
- To continuously improve my development skills through practical implementation.

✨ Features

- Home Section: Introduction and welcome section.
- About Me: Information about my background and interests.
- Skills Section: Display of technical skills and technologies.
- Projects Section: Showcase of personal and academic projects.
- Contact Section: Provides a way for visitors to get in touch.
- Responsive Design: Supports different screen sizes.
- Smooth Navigation: Makes browsing between sections easier.
- Theme Toggle: Switches between light and dark appearance, if enabled in the current version.
- Scroll Animations: Adds visual effects while navigating the page, if enabled.

🛠️ Technologies Used

Technology| Purpose
HTML5| Structures the web pages
CSS3| Styling, layout and responsive design
JavaScript| Adds interactivity and dynamic behaviour
React.js| Builds reusable user interface components

⚙️ Installation and Setup

Follow these steps to run the project locally.

Step 1: Clone the repository

git clone https://github.com/sharmistha-kaushik/My-portfolio.git

Step 2: Open the project folder

cd My-portfolio

Step 3: Install dependencies

npm install

Step 4: Start the development server

npm run dev

Note: These npm commands apply to a React project configured with Vite. If the repository uses a different setup, follow its existing configuration.

🚀 How to Use

1. Open the portfolio website in a web browser.
2. Explore the Home and About sections.
3. Review the technical skills and projects.
4. Navigate to the Contact section to get in touch.
5. Open the project links to learn more about the work.
